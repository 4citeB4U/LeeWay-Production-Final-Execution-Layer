# Machine Consciousness ↔ Production Final Execution boundary

Canonical map: [Machine Consciousness cross-repository integration v1](https://github.com/4citeB4U/Machine-Consciousness/blob/main/docs/architecture/leeway-cross-repository-integration-v1.md).

Production Final Execution receives only source-pinned, independently verified, receipt-backed release handoffs. It coordinates final deployment with Runtime Fabric and LeeWay Standards; it does not duplicate Machine Consciousness, Formula, Veritas, Receipt Authority, Continuum, Learning Ledger, or Device Bridge.

G3 simulation artifacts and `G4_ELIGIBLE_PENDING_CANONICAL_PRODUCTION_ADMISSION` are not production handoffs. A final handoff must identify source version, Formula evidence, Device Bridge execution, measured post-state, Veritas decision, Receipt Authority receipt, Continuum readback, rollback, and deployment target.
